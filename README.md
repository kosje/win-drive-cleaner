# Win 盘清理工具（WinDriveCleaner）

一个**零安装、绿色单文件**的 Windows C 盘垃圾清理工具。使用 Go 编译为静态可执行文件，
CLI 可直接运行；GUI 需要 WebView2 Runtime，缺失时自动回退到 CLI。支持 **Windows 8 / 10 / 11**（32 位与 64 位，旧系统需使用兼容的 Go 工具链构建）。

## 特性

- **两种模式**
  - **普通清理**：低风险、快速，清理系统/用户临时文件、Prefetch、缩略图缓存、Windows 更新下载缓存、WER 崩溃报告。
  - **深度清理**：在普通清理基础上额外处理回收站、系统盘临时目录、`Windows.old` 等（需管理员权限）；WinSxS 组件清理通过单独的 DISM 功能执行。
- **安全优先**
  - 绝不触碰 `System32` / `WinSxS` 受保护目录、`pagefile.sys`、`System Volume Information` 等危险目标。
  - 遇到被占用/无权限的文件自动跳过并计数，不中断整体流程。
  - 提供 `--dry-run` 演练模式：只统计可释放空间，**不删除任何文件**。
- **绿色便携**：单个 `.exe` 文件，拷到 U 盘即可在其他电脑使用，无需安装、无需 .NET 运行时。
- **图形界面（GUI）**：运行 `--gui` 启动原生 WebView2 窗口，覆盖全部功能——磁盘清理（普通/深度/演练 + 实时逐项进度 + 可中途停止）、开机自启管理（列表 + 可逆禁用/启用开关）、大文件检测、软件缓存（勾选删除）、通讯缓存、视频媒体、系统工具（DISM 组件清理 / 系统盘压缩）、清理日志查看、磁盘信息。所有耗时操作均在后台执行，**界面全程保持响应**。命令行（CLI）全部保留，二者复用同一套清理/自启核心逻辑。
- **中文界面 + 中文日志**，结果按分类列出并汇总释放空间。
- **结果清晰、不闪退**
  - 每项清理后**列出具体路径**（`└ C:\...\Temp`），让你看清"到底清理了什么"。
  - 显示**清理前后磁盘剩余空间对比**与实测释放量。
  - 清理/演练结束后**默认停在"按回车键退出…"**，方便阅读；脚本自动化时用 `--no-pause` 自动结束。
- **登录自启（可选）**：交互菜单第 8) 项可注册登录自启，每次开机倒计时后按上次设置自动执行；倒计时内按任意键可取消，也可一键关闭下次自启。仅写当前用户 Run 键，不碰系统注册表、无需管理员。
- **软件缓存 / 大文件清单**：菜单 9) 查看 AppData 各软件缓存目录大小并勾选删除；菜单 10) 列出系统盘 ≥500MB 大文件 Top 20（只列不删）。
- **系统盘压缩**：菜单 11) 用 Windows 自带 `compact` LZX 就地压缩 `C:\Windows`，释放 1-3GB（Win10/11，可逆，需管理员）。
- **删除可追溯**：所有删除前会把「路径+大小」写入 `%LOCALAPPDATA%\WinDriveCleaner\CleanerLog_<日期>.txt`，随时可查"刚才到底删了什么"。

## 使用方法

### 1. 交互菜单 / 图形界面

**Win10/11 双击 `WinDriveCleaner.exe` 默认直接打开图形界面（GUI）**（启动即请求管理员权限）；
若系统缺少 WebView2 运行时（Win8 / 早期 Win10）会自动回退到命令行交互菜单。
也可用 `--gui` 显式启动 GUI，或 `--no-uac` 跳过提权直接运行。

命令行交互菜单（`--no-uac` 或 WebView2 缺失时进入）：

```
================ Win 盘清理工具 ================
 系统: 系统盘=C:\  WINDIR=C:\Windows  架构=windows/amd64
 权限: 普通用户

  选择模式:
   1) 普通清理
   2) 深度清理(需管理员)
   3) 演练普通清理(不删除)
   4) 演练深度清理(不删除)
   q) 退出
  请输入:
```

### 2. 命令行

| 命令 | 说明 |
|------|------|
| `WinDriveCleaner.exe --standard` | 执行普通清理 |
| `WinDriveCleaner.exe --deep` | 执行深度清理（需要管理员；非管理员时自动触发 UAC 提权） |
| `WinDriveCleaner.exe --dry-run` | 演练：只统计，不删除 |
| `WinDriveCleaner.exe --no-uac` | 跳过 UAC 提权（以当前权限运行） |
| `WinDriveCleaner.exe --gui` | 启动图形界面（需 Win10/11 自带 WebView2 运行时） |
| `WinDriveCleaner.exe --scan-startup` | 只读列出全部开机自启项（注册表 Run/RunOnce + 启动文件夹） |
| `WinDriveCleaner.exe --manage-startup` | 交互管理开机自启项（可逆禁用/启用） |
| `WinDriveCleaner.exe --scan-comms` | 扫描通讯软件旧文件（只统计） |
| `WinDriveCleaner.exe --scan-cache` | 扫描 AppData 软件缓存大小（只统计） |
| `WinDriveCleaner.exe --scan-bigfiles` | 扫描 ≥500MB 大文件 Top 20（只列不删） |
| `WinDriveCleaner.exe --scan-media` | 扫描视频/录屏候选（只提示大小） |
| `WinDriveCleaner.exe --compact` | 执行系统盘压缩（compact LZX，需管理员） |
| `WinDriveCleaner.exe --version` | 打印版本 |
| `WinDriveCleaner.exe --help` | 显示帮助 |

> 深度清理涉及系统级目录，程序在**非管理员**下运行会自动请求 UAC 提权；
> 提权成功后由新的管理员进程继续执行，并在结束时暂停等待回车，避免窗口一闪而过。

### 3. 进一步释放空间（可选）

深度清理完成后，如需再榨取空间，可手动在**管理员 PowerShell / CMD** 中运行：

```bat
DISM /Online /Cleanup-Image /StartComponentCleanup
```

这会清理 WinSxS 组件备份，通常可再释放数百 MB 到数 GB，但耗时较长。

## 从源码构建

需要 Go 1.21+；首次构建需下载 `go.mod` 中的依赖。GUI 需要目标系统安装 WebView2 Runtime，缺失时回退到 CLI：

```bat
go build -trimpath -ldflags "-s -w" -o WinDriveCleaner.exe .
```

交叉编译（在 Linux/macOS 上生成 Windows 版）：

```bash
CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w" -o WinDriveCleaner.exe .
```

生成的是单文件 `.exe`；GUI 仍需要 WebView2 Runtime。

## 回归验证

在 Windows 上运行 `go test ./...` 和 `go vet ./...`。测试使用隔离的临时目录，覆盖删除统计、路径保护、目录联接、演练状态、自启项恢复、日志尾部及视频路径解析。

使用 Node.js 运行 `node --test gui_test.js`，验证 GUI 异步桥接的异常和重复任务处理。

可选的真实桌面验证（会临时打开资源管理器，验证后关闭测试窗口）：

```powershell
$env:WDC_EXPLORER_INTEGRATION = '1'
go test -run TestExplorerRevealsMediaIntegration -v
Remove-Item Env:WDC_EXPLORER_INTEGRATION
```

该验证使用包含中文、空格和逗号的目录及视频文件名，确认实际打开其父目录并选中文件。

## 安全说明

- 所有清理目标均按「临时/缓存/旧备份」语义白名单定义，未命中白名单的路径**不会被删除**。
- 被其他程序占用或无权限访问的文件会自动跳过，并在结果中计数，不会导致程序崩溃。
- 首次使用强烈建议先跑 `--dry-run` 查看可释放空间，再决定执行真实清理。
