本版把软件清理收紧为真实缓存目录，并加入可取消的扫描、实时进度及自动构建发布流程。

### 功能与修复

- **真实缓存识别**：支持 Chrome、Edge、Brave、Firefox、VS Code/Insiders、Discord/PTB/Canary、Slack 的部分已知缓存。仅清理缓存内容并保留目录，保护配置、Cookies、登录信息、Local Storage、IndexedDB、扩展和用户文件。未知目录不提供删除入口，详细路径见 ZIP 内 `CACHE_RULES.md`。
- **扫描进度与取消**：GUI 的大文件、软件缓存、视频及通讯扫描显示检查数量和当前路径，并支持取消；取消后丢弃不完整结果，窗口关闭会通知扫描停止。
- **安全边界**：保护 Windows 路径尾部点/空格、8.3 别名及异常 TEMP 配置；自动通讯旧文件清理改为默认关闭，需单独开启，常见数据库、配置和密钥文件跳过。
- **性能与稳定性**：大文件使用有界 Top N 扫描；磁盘信息在后台读取，压缩能力只检测一次。修复删除期间重扫、刷新忙状态、完成后立即重试、倒计时最后一秒取消以及 GUI 版本显示。
- **残留文件与设置**：ZIP 保存完整相对路径，避免重名、覆盖及重复打包；检查复制与关闭错误。设置使用临时文件原子替换，失败保留原内容并反馈原因。
- **自动发布**：新增 GitHub Actions，执行 amd64/386 回归测试、Go vet、前端测试和竞态检测；版本标签通过检查后构建发布包，验证附件大小、状态和 SHA256，再正式发布。

### 下载

- `WinDriveCleaner-x64.exe`：64 位 Windows。
- `WinDriveCleaner-x86.exe`：32 位 Windows。
- `WinDriveCleaner-v1.8.0.zip`：两个 EXE、README、LICENSE、审查记录和缓存规则。
- `SHA256SUMS`：三个下载附件的 SHA256 校验值。

当前构建支持 Windows 10/11，GUI 需要 WebView2 Runtime，缺失时回退 CLI。建议先关闭对应软件再清理缓存；占用或无法访问的文件会跳过。

### 验证范围

测试使用隔离临时目录，检查缓存删除与持久数据保留、路径/目录联接保护、配置替换失败、扫描取消、GUI 协议和刷新交互；没有执行真实系统清理、DISM 或系统压缩。完整自检记录见 `REVIEW.md`。
